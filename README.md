Scripts for a Raspberry PI controller for paired solenoid valves that allow changing solute concentrations inside a hollow microscopy slide on specific schedules.

serial_solenoid_control includes signaling from a USB-connected device with terminal nearby.

solenoid_8_control allows for 4 pairs (8 total) of solenoid valves to run in parallel for multiple parallelized experiments.

washout runs a modified schedule for cleaning attached tubing and valves.
